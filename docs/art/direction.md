## World style guide

Phase: Reference first. Output: Landscape 16:9, opaque background.

Reference inputs: Approved art-direction sheet.

[Individual prompt](prompts/direction/world-style-guide.txt)

```text
Create artwork for a narrative incremental bunker-defense game. Weathered industrial electrical science fiction; painterly, grounded game illustration with crisp readable silhouettes. Charcoal steel, dirty concrete, aged copper, pale cyan electricity, warm amber shelter lights. Restrained detail at small display sizes. Shared engineering signature: asymmetrical copper winding, three ceramic insulators, hand-cut fastening plate with a clipped upper-right corner. No logos, watermarks, captions, or readable text; evidence text and UI labels will be added separately.

Attach approved style, subject, and location reference images when available. Preserve their identity, proportions, materials, and engineering details exactly. If no reference is attached, use the written working design consistently. Generate one image for this request.

REQUEST: Create a visual art-direction board with material studies, color swatches, a concrete bunker, electrical hardware, ruined landscape, and engineering-signature detail. Separate clear visual regions, no labels. Establish a coherent look, not a playable scene.

COMPOSITION AND OUTPUT: Landscape 16:9, opaque background.

REFERENCE INPUTS: Approved art-direction sheet.
```
