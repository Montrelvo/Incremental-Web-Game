# First-region artwork production

This batch implements the first-region scope selected in chat: **“First-region artwork, starting with references.”** It follows [art-direction PR #4](https://github.com/Montrelvo/Incremental-Web-Game/pull/4), merged at `1d906e9ead4b229ca66753a036a06107ebbcee54`.

There are **86 covered requests and 92 PNGs**, including six revised candidates with their first passes preserved. The source files total **196.3 MiB**. All work is contained in the dedicated art section. No gameplay integration is included.

## Browse and copy

Open [the self-contained gallery](index.html) in a browser. Each image has a **Copy prompt** button, image download link, reference links and a review note. Clipboard denial opens and selects the prompt for manual copying. The HTML works as a local file; GitHub displays its source instead of running it. For GitHub viewing, use the category links below.

[Manifest](manifest.json) records exact prompts, actual reference inputs, dimensions, transparency samples, SHA-256 hashes and Git blob hashes. Each PNG has a matching JSON sidecar. References are provisional; none are represented as human approved.

## Selected revisions

Select the `-v2` files for the three environment battle plates, capacity upgrade, escape opening and defense opening. Original passes remain available for comparison.

## Production status

These are generated production studies for art review. Read [the visual review](REVIEW.md) before implementation. Pose alignment, camera consistency, animation timing, selective repainting, landmark dressing and runtime-size exports remain production tasks. This batch does not claim the acceptance criteria in the original plan are all satisfied.

Expansion regions, optional effects, later narrative requests and implementation-only UI references are outside this batch. The original [116-request plan](../../manifest.json) remains the master inventory.

## Verification

Run `python docs/art/generated/first-region/verify-art.py` from the repository root. It uses only the Python standard library to check PNG chunk CRCs and decompression, dimensions, first-row alpha samples, file hashes, references, sidecars and first-region coverage. No source image is modified.
